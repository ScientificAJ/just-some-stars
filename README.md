# Just Some Stars

Just Some Stars is a family-friendly 3D astronomy adventure about wonder, discovery, and getting home before dinner.

Planned for Google Play and the Samsung Galaxy Store, the project’s approved direction is documented here:

- [Astronomy adventure game blueprint](outputs/astronomy-adventure-game-blueprint.md)
- [Technical build plan](outputs/just-some-stars-technical-build-plan.md)
- [Implementation plan](docs/superpowers/plans/2026-08-21-just-some-stars-implementation.md)

The binding [Mirra gameplay visual target](outputs/just-some-stars-mirra-gameplay-target-v1.png) is a production-quality floor for in-game work, not promotional art.

For the current machine, tool, and ShipKit setup, see the live [agent environment guide](docs/tooling/agent-environment.md).
