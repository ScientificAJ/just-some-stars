# Just Some Stars

Just Some Stars is a family-friendly cinematic 2.5D astronomy adventure about
wonder, discovery, and getting home before dinner.

Planned for Google Play and the Samsung Galaxy Store, the project’s approved direction is documented here:

- [Astronomy adventure game blueprint](outputs/astronomy-adventure-game-blueprint.md)
- [Technical build plan](outputs/just-some-stars-technical-build-plan.md)
- [Implementation plan](docs/superpowers/plans/2026-08-21-just-some-stars-implementation.md)
- [2.5D gameplay-pivot design](docs/superpowers/specs/2026-08-25-2.5d-gameplay-pivot-design.md)
- [2.5D gameplay-pivot implementation plan](docs/superpowers/plans/2026-08-25-2.5d-gameplay-pivot.md)

The binding [2.5D Mirra gameplay visual target](outputs/just-some-stars-2.5d-gameplay-target-v1.png)
is a production-quality floor for in-game work, not promotional art. The
earlier [full-depth Mirra concept](outputs/just-some-stars-mirra-gameplay-target-v1.png)
remains historical palette, world and character-art lineage rather than a
runtime-camera or full-3D requirement.

For the current machine, tool, and ShipKit setup, see the live [agent environment guide](docs/tooling/agent-environment.md).
